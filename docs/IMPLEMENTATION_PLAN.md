- **Studied:** `PRODUCT.md`, chat components, preview components, app lifecycle guidance, relevant tests. **Deliberately not studied/copied:** Electron IPC, desktop process management, Dyad's AI orchestration, Dyad's desktop preview runtime, Pro code.
- **PRODUCT.md in short:** Dyad is a local, open-source AI app builder for non-technical users — describe an app, AI generates the code, live preview on your machine. Design principles: never a dead end (every state names what's happening and offers one obvious next action), protect the user's intent, translate technical machinery into user-goal language, one primary action per surface.
